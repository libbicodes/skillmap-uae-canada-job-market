# Data Dictionary

This file explains the columns used in the raw job postings dataset.

| Column | Description |
|---|---|
| job_id | Unique row number for each job posting |
| collection_date | Date the job posting was collected |
| country | Country where the job is located |
| city | City or region listed in the posting |
| job_title | Job title exactly as shown in the posting |
| company | Company or organization name |
| source | Website or platform where the job was found |
| job_url | Link to the original job posting |
| employment_type | Full-time, part-time, internship, contract, or temporary |
| work_mode | On-site, hybrid, remote, or unspecified |
| seniority | Internship, entry-level, junior, associate, mid-level, or unspecified |
| salary_min | Minimum salary if shown |
| salary_max | Maximum salary if shown |
| currency | AED, CAD, USD, or unspecified |
| years_experience_min | Minimum years of experience required |
| years_experience_max | Maximum years of experience required |
| education_requirement | Degree, diploma, certification, or other education requirement |
| description_short | Short summary written in my own words |
| skills_text | Tools, technologies, and skills mentioned in the posting |
| notes | Extra observations, inconsistencies, or limitations |
